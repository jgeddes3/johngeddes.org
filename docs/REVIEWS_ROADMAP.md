# Reviews roadmap

What to write next, in priority order. Everything in Tier 1 already has a live
page with a score and a "written review on the way" note — clearing those is
pure upside, and each one is a 20-minute job with the new entry system
(`npm run new:review` is only for brand-new pages; for these, open the entry in
`src/reviews/entries/`, write the blocks, flip `status` to `'published'`).
